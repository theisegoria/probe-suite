# Where these assets came from

## terrain.obj

Generated by `harness/make_assets.py`. Reproducible from that script, and
every calibrated number in the jeep task reads off it: the ramp between
z = 26 and z = 38, the cross slope between z = 48 and z = 62, the five
waypoints, and the bounds. If you change the generator, re-run the
reference solution before trusting the task.

The grid is wound counter-clockwise seen from above on purpose. PhysX culls
backfaces in triangle mesh raycasts and the vehicle suspension is raycast,
so a grid wound the other way is invisible to the simulation and the
vehicle falls through solid-looking ground.

## jeep.obj

Decorative only. The simulation reads the vehicle's dimensions from the
task prompt and never from this file, so replacing it changes the picture
and nothing else.

The shipped mesh was generated with Tripo (tripo3d.ai) from a text prompt
for a generic open-top utility vehicle, exported as GLB, converted and
decimated to 4000 triangles with `harness/glb_to_obj.py`, then fitted to
the benchmark's frame with `harness/fit_jeep.py`: uniform scale to 3.80 m
on length, centred in x and z, and dropped so the tyres touch y = -0.88,
which is the wheel centre 0.52 m below the origin less the 0.36 m radius.

Deliberately not a real manufacturer's vehicle. An earlier generation came
back as a recognisable Jeep Wrangler, seven-slot grille and all, and was
discarded: this repository is public, and a benchmark does not need a
trademarked product design in it. The shipped mesh has a flat blank front
panel, two plain round lamps, no badging and no lettering.

To replace it with your own:

```
blender --background --python harness/glb_to_obj.py -- yours.glb /tmp/j.obj --max-tris 4000
python3 harness/fit_jeep.py /tmp/j.obj            # check the numbers
python3 harness/fit_jeep.py /tmp/j.obj --write    # write assets/jeep.obj
```

`fit_jeep.py` needs nothing but Python. Blender is only for the format
conversion, and only if your mesh is not already an OBJ.

To go the other way and drop the third-party mesh entirely,
`python3 harness/make_assets.py --jeep` writes a 48-vertex box stack in its
place. The benchmark scores identically.
